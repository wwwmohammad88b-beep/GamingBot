# GamingBot 🎮

ربات تلگرام برای مدیریت گروه گیمینگ، پاسخ خودکار، آموزش پاسخ، هوش مصنوعی (Groq) و پنل مدیریت. نسخه‌ی فعلی روی حالت **وب‌هوک** کار می‌کنه (نه polling) تا بشه راحت روی یه سرور دیپلوی کرد و نیازی به روشن بودن سیستم شخصی نباشه.

## وضعیت فعلی
- ✅ راه‌اندازی، پاسخ خودکار، /learn، هوش مصنوعی (Groq)، مدیریت گروه، /panel
- ⏸ ارسال خودکار ساعتی اخبار غیرفعاله (برای سبک موندن اجرا) — `/news now` برای دریافت دستی هنوز کار می‌کنه
- ⏳ دیتابیس (MongoDB) هنوز وصل نیست — تا وصل نشه: /learn، /warn و آمار /panel کار نمی‌کنن، بقیه‌ی ربات عادی کار می‌کنه

## نصب (روی سیستم خودت، فقط برای تست لوکال)
```bash
npm install node-telegram-bot-api openai mongoose dotenv axios rss-parser express
```
فایل `.env` از قبل با توکن، آیدی ادمین و کلید Groq پر شده. بعد:
```bash
node index.js
```

## دیپلوی روی Render (رایگان)
1. کد رو تو یه ریپازیتوری گیت‌هاب بذار (از طریق آپلود فایل تو خود سایت گیت‌هاب هم می‌شه، نیازی به دستور git نیست).
2. تو [render.com](https://render.com) ثبت‌نام کن (رایگان، بدون کارت بانکی) و ریپازیتوری رو وصل کن.
3. New Web Service بساز: Build Command = `npm install`، Start Command = `node index.js`.
4. تو تب Environment، متغیرهای داخل `.env` رو یکی‌یکی اضافه کن.
5. بعد از دیپلوی، آدرسی مثل `https://gamingbot-xxxx.onrender.com` می‌گیری.
6. یک بار تو مرورگر برو به `https://آدرس-خودت/set-webhook` تا وب‌هوک ست بشه.

نکته: سرویس رایگان Render بعد از ۱۵ دقیقه بی‌فعالیتی می‌خوابه و اولین پیام بعدش ممکنه چند ثانیه طول بکشه تا بیدار بشه؛ برای یه ربات گروه دوستانه معمولاً مشکلی نیست.

## راهنمای دستورات
**عمومی:** `/start` `/help`

**مدیریت گروه** (ریپلای روی پیام کاربر، فقط ادمین گروه): `/ban` `/kick` `/mute [دقیقه]` `/unmute` `/warn`

**آموزش پاسخ** (فقط ادمین):
```
/learn
سوال: سلام
جواب: سلام رفیق ❤️
```

**اخبار:** `/news now`

**پنل** (فقط آیدی داخل `ADMIN_IDS`): `/panel`

## برای تکمیل بعدی
- گرفتن `MONGODB_URI` رایگان از MongoDB Atlas و گذاشتنش تو `.env`
- فعال کردن دوباره‌ی اخبار خودکار: `npm install node-cron` و برداشتن کامنت از خط مربوطه تو `index.js`
